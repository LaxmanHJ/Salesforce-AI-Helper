# Salesforce AI Helper

## Chrome Extension for Salesforce Tasks

A Chrome extension to streamline and automate your Salesforce workflows.

---

## Features

### Create/Update Operations
- **Objects**: Create and update Salesforce objects
- **Fields**: Manage custom and standard fields
- **Profiles**: Configure user profiles
- **Permission Sets**: Set up and modify permission sets

### Code Generation
- **Flow**: Generate Salesforce Flow configurations
- **Apex Class**: Create Apex classes
- **Test Class**: Generate test classes
- **LWC**: Build Lightning Web Components

### Flexible Pages
- Create and customize FlexiPages and Layouts

---

## Security Features

### Create or Update Security Permissions

#### Objects
Manage object-level security settings

#### Fields
Configure field-level security

#### Profiles
Set up profile permissions

#### Permission Sets
Create and manage permission sets

## Installation

### Security and Privacy
Review our [Security and Privacy Policy](#security-and-privacy)

### Browser Extension Installation

#### Chrome Web Store
Install directly from the [Chrome Web Store](https://chrome.google.com/webstore/detail/salesforce-inspector-reto/hpijlohoihegkfehhibggnkbjhoemldh)

#### Manual Installation
1. Download the extension files
2. Open Chrome and navigate to `chrome://extensions`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension folder
